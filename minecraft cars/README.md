# CustomVehicles

Независимый плагин транспорта для Paper 1.21.1. Проект не использует код или
ресурсы коммерческого `Vehicles(14.8.7).jar`.

## Возможности

- ванильная модель без ресурс-пака на `BlockDisplay`;
- выдача машины командой `/cv give [игрок]`;
- установка предметом по правому клику;
- посадка правым кликом;
- управление WASD через установленный на сервере ProtocolLib;
- ускорение, торможение, задний ход, поворот и базовые столкновения;
- возврат машины через `Shift + ПКМ`;
- параметры движения в `config.yml`.
- графическое меню `/cv config` для настройки машины и поезда;
- настройка посадки водителя по трём осям без клиентских модов;
- уменьшенное невидимое rideable-сиденье, гарантирующее передачу WASD клиентом;
- правильная высота и ориентация при установке на рельсы;
- `/cv debug` для проверки поступающего WASD-ввода.
- камера водителя отделена от курса машины; ванильное движение сиденья подавляется;
- пассивное ArmorStand-сиденье не имеет собственной клиентской физики;
- Paper-телепорт переносит корневое сиденье вместе с пассажиром через `RETAIN_PASSENGERS`;
- коллизии учитывают настоящую форму блока, включая плиты и другие неполные блоки;
- ручной рельсовый состав с динамической цепочкой вагонов;
- выдача локомотива командой `/cv give train`;
- выдача вагона командой `/cv give wagon` и сцепка ПКМ по составу;
- отцепление последнего вагона через `Shift + ПКМ` с поводком;
- два независимых пассажирских места в каждом подцепленном вагоне;
- пространственные звуки двигателя, колёс, столкновений и сцепки;
- автомобильный и поездной гудок по пробелу;
- отдельная настройка громкости машины и поезда в `/cv config`;
- локомотив следует геометрии прямых, поворотных и наклонных рельсов;
- вагон рассчитывает собственную позицию на том же пути, а не срезает повороты.
- стилизованные головной 81-717 и пассажирский 81-714 с бирюзовым кузовом,
  дверями, окнами, тележками и характерной светотехникой.
- постоянное хранение машин и составов в `plugins/CustomVehicles/vehicles.yml`;
- атомарное автосохранение положения и количества вагонов каждые 10 секунд;
- восстановление чистых моделей после штатного или аварийного перезапуска;
- меню конкретного транспорта по `Shift + ПКМ` или `/cv menu`;
- сцепка, расцепление, посадка, общие настройки и возврат всего состава через меню;
- при возврате состава каждый подцепленный вагон возвращается отдельным предметом.
- двухуровневый каталог выдачи транспорта по `/cv`, `/cv give` или `/cv catalog`;
- отдельные разделы автомобилей и железнодорожного транспорта;
- прямые команды `/cv give car|train|tram|wagon` сохранены для быстрой выдачи.
- отдельный управляемый автобус ПАЗ-3205 в автомобильном каталоге;
- меню активного транспорта по `/cv list` с владельцем, миром и координатами;
- телепортация к машине или составу кликом по соответствующему пункту;
- кнопка обновления списка и постраничный вывод при большом количестве транспорта.
- трёхсекционный трамвай Витязь-М с красно-чёрно-белым кузовом;
- сочленённые секции трамвая самостоятельно следуют кривым и наклонным рельсам;
- панорамная кабина, двери, светотехника, пантограф и четыре пассажирских места;
- выдача трамвая из железнодорожного каталога или командой `/cv give tram`.
- автономное движение поездов и трамваев по сохранённым маршрутам;
- остановки с настраиваемым временем стоянки и инструкции железнодорожных стрелок;
- обнаружение транспорта впереди, аварийная остановка и принудительная загрузка чанков;
- сохранение следующей станции и продолжение маршрута после перезапуска;
- выбор маршрута и режима движения из меню конкретного транспорта.
- меню диагностики маршрута и решений конкретного автономного состава;
- `/cv route debug <маршрут>` и `/cv road debug <маршрут>` для запуска диагностики.

Внешний вид транспорта теперь описывается YAML-файлами. Встроенные модели
автомобиля, 81-717, 81-714 и трёх секций Витязя-М поставляются как обычные
определения. Новые варианты поведения `car`, `train`, `tram` и `wagon` можно
добавлять без изменения Java-кода.

## Сборка

Нужен JDK 21. `JAVA_HOME` должен указывать на установленный JDK, но проект не
содержит и не требует пути конкретного разработчика.

macOS/Linux:

```bash
cd "minecraft cars"
./gradlew clean test build
```

Windows PowerShell:

```powershell
Set-Location "minecraft cars"
.\gradlew.bat clean test build
```

Готовый файл: `build/libs/CustomVehicles-1.3.0-beta.3.jar`.

## Модели и варианты

При первом запуске создаются каталоги:

```text
plugins/CustomVehicles/models/
plugins/CustomVehicles/vehicles/
```

В `models` находятся геометрические модели, а в `vehicles` — выдаваемые варианты
с поведением и ссылками на модели. Пользовательский файл с тем же стабильным ID
переопределяет встроенный. Если переопределение повреждено, плагин пишет точную
ошибку в консоль и продолжает использовать исправное встроенное определение.
Удаление переопределения и `/cv reload` возвращает встроенную версию.

Подробная спецификация:

- [формат визуальной модели](docs/model-format.md);
- [формат варианта транспорта](docs/vehicle-variants.md).

Краткий путь для нового автомобиля:

1. Создайте и сохраните модель в настольном редакторе.
2. Экспортируйте модель в `plugins/CustomVehicles/models/`.
3. Создайте вариант с `behavior: car` и экспортируйте его в
   `plugins/CustomVehicles/vehicles/`.
4. Выполните `/cv reload`.
5. Используйте `/cv give <id-варианта>` или каталог `/cv`.

Команда перечитывает обычный `config.yml`, модели и варианты. Активный транспорт
безопасно сохраняет уже разрешённые определения; изменения применяются к новым и
впоследствии восстановленным экземплярам. Старые предметы и записи
`vehicles.yml`, в которых ещё нет ID варианта, автоматически сопоставляются со
встроенными вариантами. Данные владельца, мира, положения и количества вагонов
сохраняются.

## Список блоков для редактора

JSON со всеми блоками Paper 1.21.1 генерируется из объявленных Paper
`BlockTypeKeys`, сопоставленных с настоящими именами `Material`, а не
поддерживается вручную. Это обходится без запуска сервера и исключает
предметы, не являющиеся блоками:

```bash
cd "minecraft cars"
./gradlew generateBlockMaterials
```

Задача обновляет ресурс редактора. Её следует повторить после смены версии Paper
и закоммитить полученный JSON.

## Разметка автономного маршрута

Маршрут создаётся один раз непосредственно в игровом мире:

```text
/cv route create line_1
/cv route stop line_1 Депо 10
/cv route stop line_1 Вокзал 20
```

Команду `stop` нужно выполнять, стоя рядом с рельсом нужной остановки. Последнее
число — время стоянки в секундах.

Для управляемой стрелки нужно смотреть на центральный рельс стрелки:

```text
/cv route switch line_1 2 south_east
```

Число `2` означает, что указанная форма рельса применяется при движении ко второй
остановке. Варианты формы удобно выбирать автодополнением клавишей Tab.

Полезные команды:

```text
/cv route list
/cv route info line_1
/cv route removestop line_1 2
/cv route removeswitch line_1 1
/cv route delete line_1
```

После разметки откройте `Shift + ПКМ` по поезду или трамваю, выберите
«Режим движения» и нажмите на маршрут. На обычной линии автопилот меняет
направление на конечных. Для кольца первая и последняя остановки должны находиться
в одной точке.

## Диагностика маршрута

После назначения транспорта на маршрут откройте список составов:

```text
/cv route debug line_1
```

Также поддерживается короткий разговорный вариант:

```text
/cv road debug line_1
```

В меню выберите конкретный поезд или трамвай. Раз в две секунды в личный чат
будут выводиться состояние и объяснение решения автопилота, следующая остановка,
расстояние, скорость, тормозной путь, направление, помеха впереди и последняя
обработанная стрелка. Для остановки:

```text
/cv route debug stop
```
